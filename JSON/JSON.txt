JSON Kya Hai?
JSON = JavaScript Object Notation

Ek line mein: Ek format hai — jismein data ko store aur transfer karte hain.

Socho aise: Jaise English ek language hai jismein log baat karte hain — waise JSON ek format hai jismein programs data exchange karte hain.

{
    "username": "rahul",
    "email": "rahul@test.com",
    "age": 20,
    "isStudent": true,
    "hobbies": ["coding", "gaming"]
}

Dekho:

Curly braces {} mein hai

Key-value pairs hain

Key hamesha string ("username")

Value kuch bhi ho sakti hai (string, number, boolean, array, object)

SON Kyun Use Hota Hai?
1. Data Store Karne Ke Liye
localStorage sirf strings store karta hai. Isliye object ko JSON string mein badalte hain:

js
const user = { username: "rahul", age: 20 };
localStorage.setItem("user", JSON.stringify(user));
// Saved: '{"username":"rahul","age":20}'
2. Data Transfer Karne Ke Liye
API se data aata hai JSON mein:

json
{
    "name": "Rahul",
    "city": "Delhi",
    "weather": "sunny"
}
Frontend aur backend dono JSON samajhte hain — isliye ye universal hai.

3. Configuration Files
package.json, tsconfig.json — sab JSON hote hain.

🎯 JSON vs JavaScript Object:
Dono same dikhte hain, par alag hain:

JavaScript Object	JSON
{ username: "rahul" }	{ "username": "rahul" }
Key bina quotes	Key quotes ke saath
Function allowed	Function nahi
undefined allowed	undefined nahi
Single quotes allowed	Sirf double quotes
🎯 JSON Ke 2 Main Methods:
1. JSON.stringify() — Object → String
js
const user = { username: "rahul", age: 20 };

const jsonString = JSON.stringify(user);
console.log(jsonString);
// '{"username":"rahul","age":20}'
Kab use karo? — localStorage mein save karne se pehle.

2. JSON.parse() — String → Object
js
const jsonString = '{"username":"rahul","age":20}';

const user = JSON.parse(jsonString);
console.log(user.username);   // "rahul"
Kab use karo? — localStorage se nikalne ke baad.

🧠 Analogy:
JSON = ek envelope jaisa hai.

Object ko envelope mein daalo → JSON.stringify (band karo)

Envelope kholo → JSON.parse (bahar nikalo)

Envelope mein sirf data hota hai — koi code, function, comment nahi.

🎯 Tumhare Project Mein JSON Kahan Use Hua:
js
// Signup mein — users array save karte waqt
localStorage.setItem("users", JSON.stringify(users));
//                                ↑ object → string

// Login mein — users nikalte waqt
const stored = localStorage.getItem("users");
const users = JSON.parse(stored);
//              ↑ string → object
Bina JSON ke: localStorage mein [object Object] save hota — jo useless hai.

🎯 Ek Line Mein:
JSON = ek format hai data ko string ki tarah store karne ka. localStorage aur APIs isi ka use karte hain.

🎯 Real-World Example:
Weather API se data aata hai JSON mein:

json
{
    "city": "Delhi",
    "temperature": 28,
    "humidity": 60,
    "forecast": ["sunny", "cloudy", "rain"]
}
Tumhare JS code mein:

js
const response = await fetch("weather-api-url");
const data = await response.json();

console.log(data.city);          // "Delhi"
console.log(data.temperature);   // 28

🧠 JSON Koi Language Nahi Hai
JSON ek "format" hai — koi programming language nahi.

Socho aise:

Cheez	Kya hai?
Hindi	Ek language hai
English	Ek language hai
JSON	Ek format hai (jaise "letter format")
JSON = data likhne ka ek tareeka. Bas.

🎯 Language vs Format — Farak:
Language (JavaScript, Python, C++):
Ismein logic likhte hain

Loops, conditions, functions hote hain

Program chalate hain

Format (JSON, XML, YAML):
Ismein data likhte hain

Koi logic nahi — bas key-value pairs

Program nahi chalate — sirf data store/transfer karte hain

🎯 JSON Ko "Seekhna" Nahi Padta
JSON ko alag se seekhne ki zaroorat nahi hai. Kyunki:

Syntax bahut simple hai — bas {} aur key: value

JavaScript object jaisa hi hai — bas quotes ke saath

Sirf 2 methods hain — JSON.stringify aur JSON.parse

10 minute mein samajh aa jata hai

Tumne already JSON use kiya hai apne project mein:

js
localStorage.setItem("users", JSON.stringify(users));
const users = JSON.parse(localStorage.getItem("users"));
Dekha? Tumne bina seekhe use kar liya. 😄

🎯 JSON Ke Rules (Bas Itne Hi):
✅ Allowed:
json
{
    "name": "Rahul",
    "age": 20,
    "isStudent": true,
    "hobbies": ["coding", "gaming"],
    "address": {
        "city": "Delhi",
        "pin": 110001
    },
    "nickname": null
}
❌ Not Allowed:
json
{
    name: "Rahul",              // ❌ key mein quotes nahi
    "age": 20,                  // ✅
    "greet": function() {}      // ❌ function allowed nahi
    "hobby": undefined,         // ❌ undefined allowed nahi
    "city": 'Delhi'             // ❌ single quotes allowed nahi
}
🎯 Kab "Seekhna" Padta Hai?
Kabhi nahi. Bas ye yaad rakho:

Kaam	Method
Object → String	JSON.stringify(object)
String → Object	JSON.parse(string)
Bas itna.

🧠 Analogy:
Socho — English ek language hai. Aur "letter format" ek tareeka hai letter likhne ka.

Letter format alag se seekhna nahi padta — bas "Dear Sir, ... Yours sincerely" yaad rakho.

JSON bhi waise hi — bas {} aur key: value yaad rakho.

🎯 Ek Important Baat:
JSON ka full form hai — JavaScript Object Notation

Matlab: Ye JavaScript ke object jaise dikhta hai. Isliye JavaScript developers ko natural lagta hai.

Python, Java, C# — sab languages JSON samajhti hain. Isliye ye universal hai.
